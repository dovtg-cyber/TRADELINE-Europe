# TRADELINE chat proxy (необязательный второй сервис)

Нужен, чтобы чат на сайте **по-настоящему отвечал** после публикации на Render: ключ модели хранится на сервере, а лимит бесплатных генераций (по умолчанию 5) проверяется на сервере. Только стандартная библиотека Python.

## Переменные окружения (Render → Environment)
| Переменная | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ API (секрет, в код не вставлять) |
| `CLAUDE_MODEL` | модель; по умолчанию `claude-sonnet-5-5` (проверьте актуальные названия и цены в документации Anthropic) |
| `FREE_LIMIT` | бесплатных генераций на посетителя, по умолчанию `5` |
| `IP_DAILY_LIMIT` | предел в сутки с одного IP, по умолчанию `25` (защита от обхода сменой браузера) |
| `PAID_EMAILS` | почты оплативших доступ через запятую; после подтверждения оплаты добавьте почту клиента |
| `ALLOWED_ORIGINS` | адрес вашего сайта, например `https://tradeline-europe.onrender.com` |
| `DB_PATH` | путь к файлу счётчиков; на Render подключите Disk к `/data` |

## Как подключить к сайту
В `public/config.js` укажите: `window.TL_CONFIG = { legalApi: "", chatApi: "https://ВАШ-СЕРВИС.onrender.com" };`

## Честные ограничения
- Список `PAID_EMAILS` ведётся вручную, а почта приходит из браузера и не проверяется сервером: это прототип. Полноценная оплата и аккаунты на сервере: этап 1 плана (`docs/legal/06-MVP-PLAN-COSTS-RISKS.md`).
- Без диска (Disk) счётчики сбрасываются при каждом перезапуске сервиса.
- Реальный вызов API модели в среде разработки не запускался (нет сети): протестировано на имитации ответа. После запуска задайте один вопрос и проверьте.
- Тесты: `python3 -m unittest discover -s tests` (8 тестов).
