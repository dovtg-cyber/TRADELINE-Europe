# 06. MVP, интеграция с GitHub/Render, расходы, риски

## 1. Интеграция с текущим стеком
Репозиторий один (`tradeline-europe`). Сайт остаётся на Render Static Site (папка `public/`). Сервер `legal-api/` добавляется вторым сервисом Render (Docker, платный Starter), База PostgreSQL на Render, Cron-задача для загрузок. Сайт включает функции после того, как в `public/config.js` указан адрес `legalApi`. До этого ничего не ломается (этап 0).

## 2. Этапы
| Этап | Содержание | Результат | Оценка (грубо, 1 разработчик + ИИ-помощь) |
|---|---|---|---|
| 0 | Страница Legal Intelligence и структурированный бриф, ответ вручную | **Готово** | сделано |
| 1 | Сервер: аккаунты, PostgreSQL, файлы, почта, роли, перенос данных платформы с localStorage | Можно принимать реальных клиентов | 3–5 недель |
| 2 | База знаний EU + PL: реестр, загрузчики, версии, разбор по статьям, FTS; 30–60 ключевых актов по таможне, НДС, безопасности продукции | Поиск по применимым версиям | 4–6 недель |
| 3 | Ассистент + проверка + Expert Review + оценочный набор 50–100 вопросов | Закрытая бета | 4–6 недель |
| 4 | Уведомления об изменениях, анализ документов и договоров, Китай/Германия | Расширение | по результатам беты |
Оценки не подтверждены опытом этой команды; уточнить после этапа 1.

## 3. Расходы (порядок величины; цены перепроверить на момент запуска)
| Статья | Оценка |
|---|---|
| Render: сервис Starter, PostgreSQL, диск | около $7 + $6 + $0,25/ГБ в месяц (данные предыдущего запуска; проверить на render.com/pricing). Бесплатная БД удаляется через 30 дней, бесплатный сервис засыпает |
| API модели | считается по токенам: стоимость исследования ≈ (вход 15–30 тыс. токенов фрагментов + выход 2–4 тыс.) × тариф провайдера. Цены не фиксировались в этом запуске: взять на странице тарифов провайдера и посчитать себестоимость одного исследования на оценочном наборе |
| Юрист: эталонные ответы, текст оговорок, Expert Review | основная переменная статья; обсудить с юристом |
| Домен, почтовый сервис | небольшие, зависят от провайдера |

## 4. Риски
| Риск | Мера |
|---|---|
| Неверное толкование при верных цитатах | Expert Review, оценочный набор, оговорки |
| Устаревшие данные (консолидация и TARIC с задержкой) | показывать дату версии и снимка, мониторинг, предупреждения |
| Условия доступа и лицензии источников не подтверждены | реестр `to_verify`, запрет использовать как доказательство до проверки |
| Утечка данных клиентов | изоляция в приложении и RLS, аудит, ЕС-регион, договоры |
| Статус услуги (консультация или информация) | решение юриста до запуска |
| Расходы на модель растут | квоты, кеш, лимиты тарифов |
| Зависимость от одного провайдера модели | адаптер `llm.py`, оценочный набор для сравнения |
| PDF без текстового слоя | пометка и ручная обработка |
